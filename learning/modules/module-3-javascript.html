Module 3: JavaScript

Variables, functions, events, and state management

What is JavaScript?

JavaScript is a programming language that runs in the browser. It adds interactivity, dynamic content, and logic to web pages.

Key Concept JavaScript is the only programming language that runs natively in all browsers. It can manipulate the DOM, respond to user events, make network requests, and much more.

State Management

This application uses a simple state-driven rendering pattern.

const state = {
  phase: "landing",
  questionIndex: 0,
  answersLocked: false,
};
src/main.js (lines 21-27)All state is in one object.
function render() {
  switch (state.phase) {
    case "landing": renderLanding(); break;
    case "question": renderQuestion(); break;
    // ...
  }
}
src/main.js (lines 88-116)The render() function checks the state and renders accordingly.
Why State-Driven Rendering? State-driven rendering makes the application predictable and debuggable. The UI is always a function of the state. If you know the state, you know what the UI looks like.

MCQ: Test Your Knowledge

Question 1

What is the difference between let and const?

  • A) let is for numbers, const is for strings
  • B) let can be reassigned, const cannot
  • C) const is faster than let
  • D) There is no difference

Answer: B

Explanation: let variables can be reassigned, while const variables cannot. However, const objects can have their properties modified.

Question 2

What does an event listener do?

  • A) Creates HTML elements
  • B) Responds to user actions
  • C) Styles elements
  • D) Stores data

Answer: B

Explanation: Event listeners "listen" for specific events (like clicks, keypresses) and execute a function when that event occurs.

Question 3

What is the purpose of document.createElement()?

  • A) To select an element
  • B) To create a new HTML element
  • C) To delete an element
  • D) To style an element

Answer: B

Explanation: document.createElement() creates a new HTML element that can then be added to the DOM.

Interview Question

Question: What is the difference between == and === in JavaScript?

Answer: == is the loose equality operator that performs type coercion before comparing. === is the strict equality operator that does not perform type coercion. For example, 5 == "5" is true (type coercion), but 5 === "5" is false (different types). Best practice is to always use === to avoid unexpected behavior.

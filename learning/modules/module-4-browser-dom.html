Module 4: Browser + DOM

How the browser renders and manipulates the DOM

The DOM (Document Object Model)

The DOM is a tree-like representation of the HTML document. JavaScript can access and modify the DOM to change the page dynamically.

HTML ↓ Browser parses HTML ↓ DOM Tree Created ↓ JavaScript accesses DOM ↓ User interaction ↓ DOM updated ↓ Browser repaints

Event Bubbling

Events bubble up the DOM tree from the target element to its ancestors.

User clicks button ↓ Event fires on button ↓ Event bubbles to parent section ↓ Event bubbles to app ↓ Event bubbles to body
Event Delegation Instead of adding event listeners to every element, you can add one listener to a parent and use event bubbling. This application doesn't use event delegation, but it's a useful pattern for large lists.

The Render Cycle

This application follows a render cycle:

State changes ↓ render() called ↓ app.innerHTML = "" (clear DOM) ↓ New HTML generated ↓ DOM updated ↓ Browser repaints ↓ User sees new content

MCQ: Test Your Knowledge

Question 1

What is the DOM?

  • A) A programming language
  • B) A tree-like representation of HTML
  • C) A database
  • D) A styling language

Answer: B

Explanation: The DOM (Document Object Model) is a tree-like representation of the HTML document that JavaScript can access and modify.

Question 2

What is the difference between innerHTML and textContent?

  • A) innerHTML is faster
  • B) textContent parses HTML, innerHTML doesn't
  • C) innerHTML parses HTML, textContent doesn't
  • D) There is no difference

Answer: C

Explanation: innerHTML parses and renders HTML tags, while textContent sets plain text without parsing HTML. textContent is safer for user input.

Question 3

What is event bubbling?

  • A) Events that float
  • B) Events propagating up the DOM tree
  • C) Events that are cancelled
  • D) Events that are delayed

Answer: B

Explanation: Event bubbling is when an event propagates from the target element up through its ancestors in the DOM tree.

Interview Question

Question: What is the difference between getElementById and querySelector?

Answer: getElementById is a faster, more specific method that selects an element by its unique ID. querySelector is more flexible and can use any CSS selector, but it's slightly slower. querySelector also has a querySelectorAll variant that returns all matching elements, while getElementById only returns one element.

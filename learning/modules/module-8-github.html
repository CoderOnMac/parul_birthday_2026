Module 8: GitHub

Repositories, Actions, Pages, and collaboration

What is GitHub?

GitHub is a web-based platform for hosting Git repositories. It provides collaboration features, issue tracking, CI/CD, and more.

GitHub for This Application This application is hosted on GitHub, which provides: repository hosting, GitHub Actions for CI/CD, GitHub Pages for deployment, and issue tracking.

Repositories

A repository (repo) is a Git project hosted on GitHub. It contains all the files, commit history, and settings.

GitHub Pages

GitHub Pages is a static site hosting service that serves websites directly from GitHub repositories.

This Application Uses GitHub Pages The application is deployed to GitHub Pages, which serves the built files from the dist/ directory. GitHub Actions automatically deploys on push to main.

GitHub Actions

GitHub Actions is a CI/CD platform that automates builds, tests, and deployments.

Automated Deployment This application uses GitHub Actions to automatically build and deploy when you push to the main branch. No manual deployment steps needed.

Issues

Issues are used for bug tracking, feature requests, and discussions.

Pull Requests

Pull Requests (PRs) are used to propose changes to a repository. They allow code review and discussion before merging.

MCQ: Test Your Knowledge

Question 1

What is GitHub Pages?

  • A) A document format
  • B) A static site hosting service
  • C) A programming language
  • D) A database

Answer: B

Explanation: GitHub Pages is a static site hosting service that serves websites directly from GitHub repositories. It's free and supports custom domains.

Question 2

What is the purpose of a Pull Request?

  • A) To pull code from another repository
  • B) To propose changes for review before merging
  • C) To request access to a repository
  • D) To delete code

Answer: B

Explanation: Pull Requests allow you to propose changes to a repository. They enable code review, discussion, and automated testing before merging the changes.

Question 3

What is GitHub Actions?

  • A) A way to create buttons
  • B) A CI/CD platform for automation
  • C) A file format
  • D) A programming language

Answer: B

Explanation: GitHub Actions is a CI/CD platform that automates builds, tests, and deployments. You can create workflows that run on events like push or pull request.

Interview Question

Question: What is the difference between a fork and a branch?

Answer: A branch is a parallel version of a repository within the same repository. It's used for feature development and is merged back via pull requests. A fork is a complete copy of a repository under your own GitHub account. It's used when you want to contribute to someone else's project or when you don't have write access to the original repository. You make changes in your fork, then submit a pull request to the original repository.

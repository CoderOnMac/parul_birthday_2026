Module 2: CSS

Styling, layout, animations, and design tokens

What is CSS?

CSS (Cascading Style Sheets) is the language used to style HTML documents. It controls the visual presentation: colors, fonts, layout, spacing, animations, and responsive design.

Key Concept CSS separates content (HTML) from presentation (CSS). This separation makes it easy to change the look without changing the structure.

CSS in This Application

All CSS is in src/styles.css. It uses CSS custom properties (variables) for a design token system.

CSS Custom Properties (Variables)

CSS variables allow you to define reusable values.

:root {
  --bg: #f7f4f1;
  --text: #1a1816;
}
src/styles.css (lines 2-22) This application uses CSS variables for all colors, spacing, and other design tokens. This makes it easy to theme the application.
Why Variables? Variables make it easy to maintain consistent design and enable theming. Change a variable in one place, and it updates everywhere it's used.

Box Model

Every element is a rectangular box. The box model consists of:

  • Content — The actual content
  • Padding — Space between content and border
  • Border — A border around the padding
  • Margin — Space outside the border
.option-card {
  padding: 1rem 1.15rem;
  border: 1px solid var(--border);
  border-radius: var(--radius);
}
src/styles.css (lines 206-215)The option cards use padding, border, and border-radius.

Flexbox

Flexbox is a one-dimensional layout method for arranging items in rows or columns.

.app {
  display: flex;
  flex-direction: column;
}
src/styles.css (lines 56-59)The main app container uses flexbox to arrange content vertically.
.options {
  display: flex;
  flex-direction: column;
  gap: var(--space-sm);
}
src/styles.css (lines 200-204)The options list uses flexbox with gap for spacing between options.

Transitions and Animations

CSS transitions and animations add motion to the interface.

Transitions

src/styles.css (line 134)Buttons have smooth transitions on hover.

Keyframe Animations

@keyframes fadeUp {
  from { opacity: 0; transform: translateY(10px); }
  to { opacity: 1; transform: translateY(0); }
}
src/styles.css (lines 472-481)The fadeUp animation is used for entrance animations.

Responsive Design

Media queries allow different styles for different screen sizes.

@media (min-width: 768px) {
  :root { --max-width: 32rem; }
}
src/styles.css (lines 541-544)On wider screens, the max-width increases.
Mobile-First Approach The application uses a mobile-first approach: styles are written for mobile first, then media queries add styles for larger screens.

Reduced Motion

The application respects user's motion preferences.

@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after {
    animation-duration: 0.01ms !important;
    transition-duration: 0.01ms !important;
  }
}
src/styles.css (lines 522-538)When users prefer reduced motion, animations and transitions are disabled.

MCQ: Test Your Knowledge

Question 1

What does CSS stand for?

  • A) Computer Style Sheets
  • B) Cascading Style Sheets
  • C) Creative Style Sheets
  • D) Colorful Style Sheets

Answer: B

Explanation: CSS stands for Cascading Style Sheets. The "cascading" refers to how styles are applied based on specificity and inheritance.

Question 2

Which CSS property is used to change text color?

  • A) text-color
  • B) font-color
  • C) color
  • D) foreground

Answer: C

Explanation: The color property sets the text color. Background color is set with background-color.

Question 3

What is the purpose of CSS custom properties (variables)?

  • A) To add animations
  • B) To define reusable values
  • C) To create layouts
  • D) To add interactivity

Answer: B

Explanation: CSS variables allow you to define reusable values like colors, spacing, and fonts, making it easier to maintain and theme your CSS.

Interview Question

Question: What is the difference between Flexbox and Grid?

Answer: Flexbox is a one-dimensional layout system (either rows or columns), while Grid is a two-dimensional layout system (rows and columns simultaneously). Flexbox is best for arranging items in a line and distributing space, while Grid is best for complex two-dimensional layouts. This application uses Flexbox because the layout is primarily one-dimensional (vertical stacking of content).

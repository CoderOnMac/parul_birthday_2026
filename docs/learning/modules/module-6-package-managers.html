Module 6: Package Managers & Build Tools

npm, Vite, and the build process

package.json

package.json is the heart of a Node.js project. It defines metadata, dependencies, and scripts.

package.json (lines 1-15) {
"name": "parul-birthday-2026",
"version": "1.0.0",
"type": "module",
"scripts": {
"dev": "vite",
"build": "vite build",
"preview": "vite preview"
},
"devDependencies": {
"vite": "^6.0.0"
}
}

Dependencies vs DevDependencies

Dependencies are needed for the application to run. DevDependencies are only needed for development.

This Application Only Has DevDependencies Since this is a static site with no runtime dependencies, Vite is the only dependency, and it's a devDependency (only needed for building).

npm Scripts

npm scripts are shortcuts for common commands.

"scripts": {
  "dev": "vite",
  "build": "vite build",
  "preview": "vite preview"
}
package.json (lines 6-10)Run with npm run dev, npm run build, etc.

package-lock.json

package-lock.json locks the exact versions of dependencies. It ensures everyone gets the same versions.

Commit package-lock.json This file must be committed to Git. GitHub Actions uses npm ci which requires this file to install exact versions.

Vite

Vite is a modern build tool that provides fast development and optimized production builds.

vite.config.js (lines 25-32) export default defineConfig({
base: resolveBasePath(),
build: {
outDir: "dist",
assetsDir: "assets",
emptyOutDir: true,
},
});

The Build Process

Source files (src/) ↓ Vite processes ↓ Bundles JavaScript ↓ Minifies CSS/JS ↓ Adds hashes to filenames ↓ Outputs to dist/

Base Path

The base path determines where assets are loaded from. For GitHub Pages, it needs to include the repository name.

BASE_PATH=/parul_birthday_2026/ npm run build
vite.config.js (lines 8-23)The base path is resolved from environment variables or auto-detected.

MCQ: Test Your Knowledge

Question 1

What is the difference between dependencies and devDependencies?

  • A) dependencies are for production, devDependencies for development
  • B) dependencies are faster
  • C) devDependencies are required
  • D) There is no difference

Answer: A

Explanation: Dependencies are needed for the application to run in production. DevDependencies are only needed during development (like build tools, linters, testing frameworks).

Question 2

What does Vite do?

  • A) Writes CSS
  • B) Provides fast development and optimized builds
  • C) Manages Git
  • D) Deploys to servers

Answer: B

Explanation: Vite is a build tool that provides fast hot module replacement during development and optimized production builds with bundling, minification, and asset optimization.

Question 3

Why is package-lock.json important?

  • A) It makes the project look professional
  • B) It locks exact dependency versions
  • C) It's required by law
  • D) It makes the project faster

Answer: B

Explanation: package-lock.json locks the exact versions of dependencies, ensuring everyone who runs npm install gets the same versions. This is crucial for reproducible builds.

Interview Question

Question: What is the difference between npm install and npm ci?

Answer: npm install installs dependencies and may update package-lock.json if versions have changed. npm ci (clean install) installs dependencies exactly as specified in package-lock.json and never modifies it. npm ci is faster and is recommended for CI/CD environments because it ensures reproducible builds.
